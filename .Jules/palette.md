## 2026-07-29 - [Accessible Custom Toggle Switch Pattern]
**Learning:** Standard custom-styled checkboxes that use `display: none` to hide the original `<input type="checkbox">` are completely inaccessible to screen readers and keyboard users because they are removed from the document tab order and the accessibility tree. By visually hiding the input using a zero-dimension clipping pattern (absolute positioning, `clip: rect(...)`, `width: 1px`, `height: 1px`) and pairing it with a focus ring using `input:focus-visible + .toggle-slider`, we preserve full keyboard navigation (Tabbing and Spacebar activation) and screen reader support while keeping custom visual styles.
**Action:** Always visually hide checkbox inputs in custom toggle switches instead of using `display: none` or `visibility: hidden`, and always declare custom `:focus-visible` styles on the companion visual element to guarantee keyboard accessibility.
