## 2025-02-15 - [Visually Hidden Toggles and Keyboard Focus States]
**Learning:** Using `display: none;` on form inputs (like checkbox elements wrapped in a custom toggle switch layout) completely excludes them from the page's tab/focus order and accessibility tree. This makes them entirely inaccessible to keyboard-only and screen-reader users. Replacing `display: none;` with a standard visually hidden / screen-reader-only CSS pattern keeps the element focusable and navigable while preserving the custom visual design of the toggle switch.
**Action:** Always avoid `display: none;` for interactive inputs when styling custom checkboxes, radios, or toggles. Use absolute positioning, zero dimensions, and clip properties to visually hide the native input while maintaining keyboard focusability and ARIA state mapping via CSS `:focus-visible` to custom visual containers.
