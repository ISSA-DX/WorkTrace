## 2026-05-24 - [Focus-Visible & Submit Loading Feedback]
**Learning:** Adding `:focus-visible` styling dramatically improves accessibility for keyboard-only users by highlighting focused elements, without cluttering the UI for mouse users. Combining this with disable-on-submit buttons prevents duplicate requests and gives users clear feedback on pending submissions.
**Action:** Always include a visual focus state for all custom button/interactive classes and add disable-on-submit behaviors to critical form actions to improve UX and avoid double post requests.
