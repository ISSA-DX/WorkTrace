## 2026-07-13 - Accessible Toggle Switch and Form Submission UX
**Learning:** Hiding the native `<input type="checkbox">` of custom toggle switch components using `display: none;` prevents them from participating in keyboard tab orders and makes them invisible to screen readers. To ensure accessibility, form inputs must instead be styled with standard visually-hidden CSS patterns (clipped 1px size), and focus indicators (`:focus-visible` / `:focus`) must be actively mapped to the corresponding custom visual components (like the toggle slider) to assist keyboard navigation.
**Action:** Always avoid `display: none` on interactive form controls. Instead, visually hide them using clipped dimension properties and style visual focus outlines on sibling decorative elements using focus selectors.
