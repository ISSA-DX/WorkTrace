## 2026-07-15 - Dual-Layer Form Auto-Fill (LocalStorage + Remote Lookup)
**Learning:** For daily transactional employee forms (like clock-in/out), users experience high cognitive load re-entering matching details (ID, Name, Email, Position). Implementing a dual-layer auto-fill—where personal devices load from client-side `localStorage`, and shared/kiosk terminals resolve details from a remote database via Staff ID lookup on field blur—covers both usage modalities seamlessly. Placing the lookup key (Staff ID) first in the form layout is critical to establishing an intuitive top-to-bottom auto-complete tab order.
**Action:** Always structure transactional and repetitive forms with the lookup/identifying input field at the top, and back it with both client-side persistence and remote lookup to cover all device environment contexts.
